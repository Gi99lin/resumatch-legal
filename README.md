# ResuMatch — legal documents

Public terms of use and privacy policy for the ResuMatch Telegram bot
([@GigglinReviewbot](https://t.me/GigglinReviewbot)), published via GitHub Pages
so that payment providers and users have a stable URL to read them at.

Russian (canonical):
- [Пользовательское соглашение](https://gi99lin.github.io/resumatch-legal/terms.html)
- [Политика конфиденциальности](https://gi99lin.github.io/resumatch-legal/privacy.html)

English (mirror, kept in sync with the Russian text):
- [Terms of Use](https://gi99lin.github.io/resumatch-legal/terms-en.html)
- [Privacy Policy](https://gi99lin.github.io/resumatch-legal/privacy-en.html)

Each document links to its counterpart in the other language (the "RU"/"EN"
link next to the title) and to the sibling document in the same language
(footer). Support contact: Telegram [@Gigglin](https://t.me/Gigglin) or
support@gigglin.tech.

Plain static HTML, no build step. Edit the files and push; GitHub Pages serves
them directly from the `main` branch.

When changing a document, update its `Редакция от ...` / `Revision of ...`
date at the top of the file — it is the only version marker users have — and
make the same change in its other-language counterpart so RU and EN never
drift apart.
