# ResuMatch — legal documents

Public terms of use and privacy policy for the ResuMatch Telegram bot
([@GigglinReviewbot](https://t.me/GigglinReviewbot)), published via GitHub Pages
so that payment providers and users have a stable URL to read them at.

- [Пользовательское соглашение](https://gi99lin.github.io/resumatch-legal/terms.html)
- [Политика конфиденциальности](https://gi99lin.github.io/resumatch-legal/privacy.html)

Plain static HTML, no build step. Edit the files and push; GitHub Pages serves
them directly from the `main` branch.

When changing either document, update the `Редакция от ...` date at the top of
the file — it is the only version marker users have.
